# AthenISA Tools

The AthenISA toolchain provides the reference assembler and disassembler for creating and inspecting programs that run on AthenISA processors.

## Tools

| Executable | Purpose | Guide |
| --- | --- | --- |
| `athenisa-asm` | Assemble `.athe` source code into machine code | [Assembler guide](https://github.com/morsoth/athenisa/blob/main/tools/assembler/README.md) |
| `athenisa-dis` | Convert binary or hexadecimal machine code into canonical assembly | [Disassembler guide](https://github.com/morsoth/athenisa/blob/main/tools/disassembler/README.md) |

The assembler and disassembler use the same instruction encodings and file formats. A binary generated by `athenisa-asm` can therefore be passed directly to `athenisa-dis`.

## Typical workflow

An AthenISA program normally starts as a `.athe` source file:

```sh
athenisa-asm program.athe
```

This produces `program.bin`, a raw machine-code image suitable for loading into instruction memory. Optional assembler outputs provide a hexadecimal image, symbol map, and addressed instruction listing.

The generated machine code can be inspected later with:

```sh
athenisa-dis program.bin
```

The disassembler emits real AthenISA instructions. Original labels, constants, comments, formatting, and pseudo-instructions are not stored in machine code and cannot be recovered.

## Installation

### Prebuilt package

Download the package for your system from [GitHub Releases](https://github.com/morsoth/athenisa/releases). Each package contains both tools.

| System | Release package | Executables |
| --- | --- | --- |
| Linux x86-64 | `athenisa-tools-vX.Y.Z-linux-x86_64.tar.gz` | `athenisa-asm`, `athenisa-dis` |
| Windows x86-64 | `athenisa-tools-vX.Y.Z-windows-x86_64.zip` | `athenisa-asm.exe`, `athenisa-dis.exe` |

After extracting the Linux package:

```sh
chmod +x athenisa-asm athenisa-dis
./athenisa-asm --version
```

After extracting the Windows package:

```powershell
.\athenisa-asm.exe --version
```

### Run from source

A current stable Rust installation is required to run the tools directly from the repository:

```sh
git clone https://github.com/morsoth/athenisa.git
cd athenisa/tools
cargo run -p athenisa-asm -- --version
```

The prebuilt packages are the recommended option for users who do not need to modify the tools.
